# iBuilt — A platform for creators to share their projects and discover new launches

- Built by Amandeep SINGH
- GitHub: @amxnos20

iBuilt is a community-focused platform designed to bring together creators, makers, and innovators in one place. It allows builders to showcase their projects while exploring what others are launching and receiving meaningful feedback from the community.

The platform provides a smooth and engaging **product discovery experience** with the following capabilities:

## Product Management

- Simple and intuitive product submission with complete project details
- Smart categorization system with tags for better organization
- Highlighted section for featured products
- Feed displaying the latest product launches
- Dedicated product pages containing full project information
- Support for various project types including apps, AI tools, SaaS platforms, and creative projects

## User Experience

- Visually appealing and interactive product cards
- Structured dashboard for managing submitted products
- Responsive interface optimized for both mobile and desktop devices
- Real-time voting mechanism (upvotes and downvotes)
- Tools for browsing and discovering new products
- Toast notifications to inform users about actions and updates

## Technical Foundation

- Built with **Next.js 16 using the App Router architecture**
- Secure authentication powered by **Clerk** (Passkeys, GitHub, Google)
- **NeonDB PostgreSQL** database for reliable and scalable storage
- **Drizzle ORM** ensuring type-safe database interactions
- Administrative panel for moderating and managing submitted products
- Protected API routes and application endpoints

This project is ideal for creators, developers, founders, and anyone interested in sharing their work or exploring innovative ideas. **Project Lab** showcases how modern web technologies can be used to build interactive community platforms while focusing on design quality and user experience.

## ⚡ Features

### 🛠️ Core Technologies

- 🚀 **Next.js 16 App Router** for server-side rendering, routing, and API endpoints using Server Components
- ⚛️ **React 19** for building dynamic and reusable user interface components
- 🔑 **Clerk** for authentication with Passkeys, GitHub, and Google login
- 🎨 **ShadCN UI** for accessible and customizable React components
- 💾 **NeonDB (PostgreSQL)** for serverless storage of products and user data
- 🗄️ **Drizzle ORM** for type-safe queries and database migrations
- 📜 **TypeScript** to provide static typing and improve development reliability
- 💅 **TailwindCSS 4** for responsive and utility-based styling
- ✅ **Zod** for schema validation and form data validation
- 🎯 **React Hook Form** for optimized form state management

### 💫 Application Features

- 📝 Product submission with validation and moderation workflow
- 🎨 Interactive and visually rich product cards and layouts
- 🔒 Secure file upload and processing
- 🔐 Protected application routes and backend APIs
- 👨‍💼 Admin dashboard for product moderation and management
- 📊 Sections for featured products and recently launched projects
- 📱 Fully responsive layout for mobile and desktop screens
- 🔄 Real-time updates with path revalidation
- 🚀 Ready for production deployment
- 🔔 Toast notifications for submission status, updates, and error messages
- 📈 Performance improvements and optimizations
- 🔍 SEO-optimized product pages
- 🗳️ Community voting system for product ranking
- 🏷️ Tag-based product organization and filtering
