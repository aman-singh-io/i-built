## 📌 Overview

**iBuilt** is a community-focused platform designed to bring together creators, makers, and innovators in one place. It allows builders to showcase their projects while exploring what others are launching, discovering new ideas, and receiving meaningful feedback from the community.

This project showcases modern full-stack engineering standards: secure authentication, serverless database scaling with type-safe operations, an interactive product discovery experience, and rigorous engineering methodologies.

---

## 🛠️ Core Technologies

- 🚀 **Next.js 16 App Router** for server-side rendering, routing, and API endpoints using Server Components
- ⚛️ **React 19** for building dynamic and reusable user interface components
- 🔑 **Clerk** for secure authentication with Passkeys, GitHub, and Google login
- 🎨 **Tailwind CSS 4** for responsive utility-based styling
- 🧩 **shadcn/ui** for accessible and customizable React components
- 💾 **NeonDB (PostgreSQL)** for serverless storage of products and user data
- 🗄️ **Drizzle ORM** for type-safe queries and database migrations
- 📜 **TypeScript** for static typing and improved development reliability
- ✅ **Zod & React Hook Form** for schema validation and optimized form state management

---

## 💫 Application Features

- 📝 Product submission with complete validation and moderation workflow
- 🎨 Visually appealing, interactive product cards and modern layouts
- 🔒 Secure authentication and protected application routes & backend APIs
- 👨‍💼 Admin dashboard for product moderation, management, and tracking
- 📊 Highlighted sections for featured products and recently launched projects
- 📱 Fully responsive layout optimized for mobile and desktop screens
- 🔄 Real-time updates with path revalidation and toast notifications
- 🗳️ Community voting system (upvotes and downvotes) for product ranking
- 🏷️ Tag-based categorization and filtering system for apps, AI tools, and SaaS platforms
- 🔍 SEO-optimized product pages for maximum discoverability
